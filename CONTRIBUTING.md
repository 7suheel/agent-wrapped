# Contributing to agent-wrapped

Thanks for helping! This project is small on purpose: one command, zero setup,
nothing leaves the user's machine. Contributions that keep it that way are very welcome.

## Ground rules

1. **Privacy first.** No network requests, no telemetry, no analytics, ever. The CLI
   reads local files and writes local files. PRs that add a network call won't be merged.
2. **Never commit real logs.** Test fixtures are hand-written fakes (`test/fixtures/`)
   or generated by `scripts/generate-demo-data.ts`. Don't paste real session lines,
   even redacted ones: prompts and paths leak more than you'd think.
3. **Be resilient.** Log formats change without notice. A broken line, a missing field
   or a new message type must never crash the tool; skip it and count it.

## Setup

```bash
git clone https://github.com/<you>/agent-wrapped
cd agent-wrapped
npm install        # Node 22+ for development (the CLI itself runs on Node 18+)
npm run check      # typecheck, lint, format check, tests, build
```

Try it on your own logs, or on a fake year:

```bash
npm run build && node dist/cli.js            # your real logs
npm run demo                                 # fake year -> docs/example*.png
node dist/cli.js --dir .demo-data --json     # stats as JSON
npm run demo:gif                             # re-record docs/demo.gif (needs vhs, ttyd, ffmpeg)
```

## Where things live

| Path                       | What                                                  |
| -------------------------- | ----------------------------------------------------- |
| `src/parsers/claude.ts`    | Claude Code `.jsonl` parser (format notes at the top) |
| `src/paths.ts`             | Where logs live on Windows, macOS and Linux           |
| `src/pricing.ts`           | **Model prices.** Update this when prices change      |
| `src/stats/compute.ts`     | All the numbers                                       |
| `src/stats/personality.ts` | **Personality rules.** Add your own archetype here    |
| `src/stats/phrases.ts`     | Phrases we count ("You're absolutely right!")         |
| `src/render/terminal.ts`   | The animated terminal reveal                          |
| `src/card/card.ts`         | The PNG cards (satori layout, no React)               |

## Good first contributions

- **New personality.** Add an entry to `ARCHETYPES` with a `score` (your metric divided
  by a threshold; 1 or more qualifies) and a test in `test/stats.test.ts`.
- **New phrase.** Add a regex to `AGENT_PHRASES` or `USER_PHRASES`, plus a fixture line.
- **Pricing update.** Edit `MODEL_PRICES`, bump `PRICING_UPDATED`, cite the source in the PR.
- **New agent (Codex, Cursor, ...).** Write a parser that returns the same `AgentEvent`
  objects as `src/parsers/claude.ts`, with fake fixtures. Open an issue first so we can
  agree on the format notes.

## Pull requests

- Keep PRs focused; one feature or fix each.
- Run `npm run check` before pushing; CI runs it on Linux, macOS and Windows.
- If you change the card design, include a before/after screenshot (from `npm run demo`).
